# 简易贪吃蛇游戏 🐍

一个用 Python 开发的经典贪吃蛇游戏，可直接在电脑上运行。

## 功能特性

- 🎮 经典贪吃蛇游戏玩法
- ⌨️ 方向键控制蛇的移动
- 🔴 吃食物获得分数
- ⏸️ 暂停/继续游戏
- 🔄 游戏结束后可重新开始
- 📊 实时显示分数

## 安装要求

- Python 3.7+
- pygame 库

## 安装步骤

1. **克隆或下载本项目**
   ```bash
   git clone https://github.com/hfdv555/666.git
   cd 666
   ```

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

3. **运行游戏**
   ```bash
   python snake_game.py
   ```

## 游戏操作

| 按键 | 功能 |
|------|------|
| ⬆️ ⬇️ ⬅️ ➡️ | 控制蛇的方向 |
| SPACE | 暂停/继续 |
| R | 游戏结束后重新开始 |
| ESC 或 Q | 退出游戏 |

## 游戏规则

1. 控制蛇吃红色的食物
2. 每吃一个食物，蛇会增长一节，得分增加 10 分
3. 蛇不能撞到墙壁或碰到自己的身体
4. 撞到障碍物后游戏结束
5. 尝试获得最高分数！

## 游戏画面

- 🟢 绿色方块：蛇的身体（亮绿色是头部）
- 🔴 红色方块：食物
- 灰色网格：游戏区域边界
